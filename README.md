✨ Lustre & Co. — Modern Imitation Jewelry Store

A full-stack, production-ready e-commerce application for an imitation jewelry brand.
Built with a Vite + React storefront and a NestJS + MongoDB REST API backend.

🛍️ Features
- Product catalog with filters, search, categories & collections
- Quick view modal, wishlist, and shopping bag
- Secure JWT authentication (login, signup, forgot/reset password)
- Full checkout flow with COD and Razorpay payment gateway
- Order tracking, order history & customer account management
- Newsletter subscription with promo coupon support
- 3D hero section powered by React Three Fiber
- Page transitions with Framer Motion
- Fully responsive with mobile navigation drawer
- Admin panel for managing products, orders, categories, reviews, coupons, pages, FAQs, settings & more
- Swagger API docs at /api/docs

🛠️ Tech Stack
Frontend  → React 18, Vite, React Router, Framer Motion, Three.js, Lucide Icons
Backend   → NestJS 12, Mongoose, Passport JWT, Razorpay, Swagger
Database  → MongoDB
